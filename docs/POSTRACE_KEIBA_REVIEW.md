# 結果付き.keiba のレース振り返り（2026-11-11）

## 画面の動作

「保存した予想を開く」から元の`.keiba`を開き、レースを選択すると、「結果・払戻の取り込み（元の予想は変更しません）」が表示されます。

1. 「着順・最終単勝 CSVひな型」「馬券種別の払戻 CSVひな型」をダウンロードします。
2. ひな型に結果公表後の正確な着順・最終単勝倍率・最終人気・実際の4角位置と、公式払戻（的中組合せ・円・基準額）を記入します。**取得できない値は空欄。架空値は入れません。** 馬別CSVだけの利用も可能です。
3. 情報の確認元を入力しCSVをアップロード。レースIDは開いているレースから、馬番・馬名は元の予想から厳密に照合。取込みエラーのときはコピーは作成しません。
4. 一覧の下に独立した折りたたみ「レース振り返り」が出現。**通常の横一覧と全く同じ表示列・データ・順番**を先に表示し、その後ろへ「実着順／最終単勝／最終人気／実4角」の4列を追加。下には式別の払戻表。
5. 「結果・払戻付き.keibaコピーを保存」すると元ファイルを上書きせず、新しいコピーが作られます。次回この`.keiba`を開けば結果と払戻が復元されます。

## 払戻CSV例

```csv
式別,組合せ,払戻金,基準額
単勝,3,860,100
複勝,3,260,100
馬連,3-7,1630,100
ワイド,3-7,580,100
馬単,3-7,3400,100
3連複,2-3-7,12500,100
3連単,3-7-2,62400,100
```

金額は**公式の払戻（基準額あたり）**であり、実際の購入金額や収支ではありません。馬連・ワイド・3連複は組合せを順序なしとみなし、馬単・3連単は順序を保持します。複勝など複数的中組合せも記録可能。

## データと安全性

- `snapshot.json` 内の**`races[].race_results_v1`** に後日結果の独立記録を保存。`prediction_result`、`horses`、`mobile_snapshot`、元のオッズ履歴を変更しません。
- 結果付き`.keiba`は既存形式の`manifest.json` / `snapshot.json`を保持し、ハッシュを更新した通常の`.keiba`です。読込時に整合性検証。
- 元の「全頭予想・比較一覧」はそのまま。振り返り表の「自分の✓」は閲覧専用のため無操作。振り返り側の馬名も元一覧の選択操作と連動しません。
- 振り返りの表には結果を入れない予想用指標も残り、**予想時と結果後の違い**を一画面で照合できます。
- 過去結果を予想の指数・Top5・印や単勝オッズに混ぜません。未取得なら未取得と表示します。
- 現在、JRA/NARの結果・払戻の自動取得は行いません。手元のCSVからの取込みです。
- 上書きしたい場合も元の`.keiba`から別コピーを作成してください。異なる確定結果で既存結果を無言で置換しません。
