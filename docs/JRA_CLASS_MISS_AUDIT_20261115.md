## 実データに確認されたクラス誤認

発走前 `class_label` / `class_rank` が芝コースの「Aコース／Bコース」を地方級の A級(64) / B級(50) と解釈したと考えられる**11/93R**を確認。具体例：

- 2026-11-14 福島9R「土湯温泉特別」: 旧 A級(64) → `race_data2` は **1勝クラス**（正しい class_rank=30）。
- 2026-11-14 東京10R「奥多摩S」: 旧 B級(50) → **3勝クラス**（正しい class_rank=50、数値が偶然一致してもラベルは誤り）。
- 2026-11-08 東京9R「百日草特別」: 旧 B級(50) → **1勝クラス**。
- 2026-11-08 福島11R「みちのくS」: 旧 A級(64) → **オープン**。

**原因:** `core/jra_notebook_logic.py` の `race_class_info_from_soup` がレース本文の `RaceData02` で公式条件を見る前に、`RaceData01` 内の単独の「A」「B」を旧地方級の正規表現で拾う順序だった。過去走解析と当日レース解析の両経路に共通。

## 修正内容と影響範囲

1. GradeType / 重賞アイコンは先に判定し、その後 `RaceData02`・過去レースの `.data_intro .smalltxt` に明記された新馬／未勝利／1〜3勝／OPを優先する。
2. コース区分の単独 A/B/C から「A級/B級/C級」を捏造しない。**明記された地方 A級は維持**。
3. 既存の JRA ランクや印の数値を過去データから事後書換しない。修正後の最新の発走前保存データで再検証する。
4. 保留：モデルBへの一括正式切替、レースクラス別の強制加点、未検証の重賞／馬場補正、SABCDの閾値変更。3日間だけで勝てると言い切らない。

## 次の検証ゲート

- 回帰テスト：同じA/Bコースでも1〜3勝・未勝利・OP・重賞のクラスを正しく読み分け、地方A級が壊れない。
- 新規の発走前 .keiba で当日・前走のクラス／昇級／降級を検算。旧ファイルは原予測を保持。
- 影響を受ける正式順位・SABCDの新旧差分を、同一レースの発走前予測と未使用日の実結果で比較（Top1勝率、Top5勝ち馬・3着内捕捉、クラス別内訳）。
- NARは変更しない。重賞の過去傾向は現在も研究表示のみ（馬場状態・脚質・ペースの不足分は未検証）。

## 注意事項

この監査で「誤分類が最終順位の何レースを損ねたか」は未確定。class_rank は実戦評価で参照されるが、同じ誤分類が全馬に適用される場合、順位への影響は馬ごとの前走クラス次第となる。原HTMLと当時のコード全体で再計算した比較を経ない限り、因果効果や修正後の勝率改善量を断定しない。

4. オッズやレース結果を学習・評価の同じ日付に混ぜない。最低限、時系列で既存日を学習用、新しい日を評価専用に分離する。
