# Dashboard研究列：クラス・重賞注目（2026-11-11）

目的：純能力がクラス間の強弱を未解決のままのため、**一律加点をせず**、過去の重賞・同級・格上好走を根拠付きで一覧表示する。

## 表示

- 通常の「全頭予想・比較一覧」で、純能力の直後に「クラス・重賞注目」を追加。文字列で検索・絞り込み・ソート可能。
- 背景情報は列のホバーと馬名をクリックした馬別詳細の「注目根拠」から読める。スマートフォンは詳細に表示。
- 「格上3着内」「重賞好走歴」「同級3着内」「前走から昇級」「重賞出走歴」「特記事項なし」「比較資料不足」のいずれか。
- 正式純能力スコア、正式Top5、印、騎手、オッズ、購入判断などは変更しない。

## 判定

- 馬の過去3走の保存資料からのみ算出（候補抽出時点より前の開催日）。
- クラスの上下比較はJRA/NAR同一主催、平地／障害同一、年齢区分同一かつ明示的、NARは同一場のみ。数値階層の推測やJRAの1勝と地方C級の直接比較はしない。
- 重賞出走・3着内は過去級にG1〜G3またはJpn1〜Jpn3、明示された重賞がある場合の歴史的事実。馬場の違いは説明に表示。単なる出走経験はプラス評価扱いにしない。
- 自動加点0。全馬を新しいランキングに並べ替えない。

## 限界

前回の50ファイル横断研究で確認できた、過去3走以前の履歴や別ファイル保存レースの厳密な級ヘッダは、通常の1ファイル読込だけでは参照できない。今回のUI研究版は **現時点の1ファイルに残された近3走の情報** に限る。クラス判定不能は「比較資料不足」と示し、重賞実績の好走率や追加加点を証明したとは主張しない。将来、許容された履歴インポートを付けた後、研究用ブリッジPR #28のID・予想時刻照合を流用できる。

検証：tests/test_class_grade_attention.py で年齢区分不一致、主催/場不一致、重賞好走歴と単なる出走歴、表示専用・無加点等を確認する。
