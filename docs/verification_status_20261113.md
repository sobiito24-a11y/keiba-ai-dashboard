## 重要な区別

1. **HTTP疎通成功** ≠ **レースHTML解析成功** ≠ **単複18頭照合成功** ≠ **Streamlit上で反映成功**。各段階を混同しない
2. GitHub Actionsのテストは本番Streamlit Cloudの接続許可・画面表示を保証しない
3. 過去の勝ち馬単勝払戻だけで「馬連が荒れる」「逃げ有利」「当該馬は買い」と推定しない
4. 2021/22欠落を3年間の結果で補って「5年検証済み」と記載しない
5. 過去レースに結果を知った後の分析結果を使用するときは「後日検証」と明記し、当時の事前予想と扱わない
