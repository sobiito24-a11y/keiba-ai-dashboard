# NAR馬体重更新・新SABCD別連対率検証（研究用）

## 対応画面

DashboardのNAR予想画面内、「⚖️ 馬体重更新・ランク別検証（研究用）」を開きます。JRA・MobileのHTMLアップロード版は今回の変更対象外です。

1. 馬体重発表後・当日の対象レースを選び、**当日馬体重を更新（楽天競馬）** を押します。サーバーから楽天競馬の公開出走表へ単発でアクセスします。開催日・競馬場・R・馬番・馬名を照合した上で、今回kg、前走比kg、過去の連対時体重（最小〜最大kg）、範囲内/外、範囲までの距離を表示します。発表前は未取得のままです。発走時刻は保存された予想データから読みます。楽天のサーバー側更新時刻は取得できず、記録するのは**当アプリの受信時刻**です。
2. 公開ページへのアクセスがブロックされる等で失敗した場合は「更新できないとき：出走表HTMLを取り込む」から、**同一レースの横の出馬表HTML**を選んで照合します。保存HTML自体の作成時刻は証明できません。アップロード時刻を受信時刻として記録します。
3. 馬名を開くと、その馬の馬体重比較が詳細欄に出ます。ただし**ランク、正式Top5、印、指数、オッズ、買い目への反映はゼロ**です。
4. 発走後、「レース後：結果を照合する」から**楽天競馬の確定着順を取得**を押します。結果は予想や発走前馬体重とは別の領域に保存します。
5. 「蓄積データ・SABCD別の1着／2着以内／3着以内率」で集計を確認できます。分類はS〜D×連対時範囲内/外の10群、分母と実際の1着/2着以内/3着以内件数を表示します。

## 保存・取り込み

- 研究記録はStreamlitの現在のブラウザセッション内に置きます。**サーバー側の永続保存ではありません。**
- 複数日にわたり記録を保持するには、下部の「研究用の全レース馬体重・結果JSONを保存」でファイルをダウンロードし、次回「別の日に保存した研究用JSONを追加する」から読み込みます。
- JSON内の既存の馬体重観測は追記専用で、同じ観測IDの重複は除外します。結果記録が矛盾していれば上書きせず停止します。取得時刻は提供元の公表時刻を保証しません。
- 研究JSONは既存の.keiba予想・モデルを変更しません。取り込んだデータが公的に署名済みとは扱いません。後から編集されたJSONの真偽までは保証できません。

## 検証ルール

- **各レースの発走前最終観測を1件だけ**利用。1レースの繰り返し更新を別サンプルとして数えません。
- 保存した発走時刻より前に受信した観測で、独立AIの保存済み新SABCDが照合された馬だけ対象。発走後の取得・時刻不明・体重未発表・連対時範囲不明・取消/除外・結果未確定は分母から除外します。
- 「連対時馬体重」は楽天競馬が載せた好走履歴の範囲です。馬の「理想体重」や今回も連対する保証を意味しません。
- 各群30頭未満では参考値。個別のレースの勝敗や後日取得の体重を発走前のAI評価に混ぜません。
- 学習した期間と新しい開催日を分ける検証は、学習25R・未使用10R以上・異なる開催日10日以上で初めて実行します。過去70%の日付でSABCDのみとSABCD＋馬体重の連対率を推定し、後半30%でBrierスコアを比較します（低いほど良い）。**比較表示のみで、新SABCDの変更はしません。**
- 1着率・2着以内率・3着以内率は「同じグレードの中で範囲内外だとどのくらい違うか」を知るための記述統計。サンプル数・開催場・年齢・馬場状態・人気などの違いの影響を受けます。実際の予測精度向上には、期間分離後も検証が必要です。

## サイトへのアクセス

楽天競馬の公開表示ページを人が操作したときに1回だけ読み取ります。サイト側が制限・ブロックした場合は無理に回避せず保存HTML方式へ切り替えてください。短時間の連続アクセスは抑止（同じレース120秒、全体30秒）。ログイン情報・裏API・自動巡回・定期スクレイピングは使いません。
