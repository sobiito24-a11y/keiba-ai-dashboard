# クラス比較：保存履歴からの根拠復元（研究用、2026-11-11）

このブランチは、既存の純能力・正式Top5・印を変更せず、過去レースのクラス照合を厳密にする研究モジュールを追加する。

## 背景

現行 `core/newspaper_v2_enrichment.py` は新聞の過去走を最大3走まで解析する。保存された `.keiba` に新聞HTMLが含まれない場合、元データがない過去5～10走を捏造してはならない。

既存の `.keiba` をレースID・馬ID・保存日時で結合すれば、別の予想日に保存されていた同じ馬の過去走情報を補える。研究用監査では、50ファイル、重複除外2,178R（JRA552R／NAR1,626R）を使用。

| 項目 | JRA | NAR |
|---|---:|---:|
| 過去走を増やせた馬 | 354 | 3,040 |
| 新しく特定した過去走 | 370 | 4,195 |
| 過去5走以上の馬 | 16 | 975 |
| クラス比較できた過去走 | 2,978 | 2,452 |
| 昇級 | 335 | 119 |
| 降級 | 15 | 53 |

クラス比較可能な走は全39,967走のうち5,430走。うち同級4,908走。比較可能なクラス変化は昇級454走／降級68走。**この件数は的中率の改善を意味しない。**

## 新モジュール

`core/class_history_bridge.py` の二関数：

- `verified_past_context`：過去レース自身の保存済み事前ヘッダに同一馬IDが存在し、保存時刻が今回の予想時刻より前なら、欠損した過去クラス・年齢条件を補完する。矛盾する既知値を上書きしない。
- `class_transition`：JRA/NAR、年齢条件、平地/障害、NARは同一競馬場を厳密に確認し、昇級／降級／同級／比較不能を返す。

`tests/test_class_history_bridge.py` は、取得時刻の逆流、馬ID・競馬場・年齢条件の不一致を含む6ケースを確認する。

## 限界・非対象

- 元の過去レースが保存されていなければ、過去年齢区分やクラスを推測で補わない。
- NARのC2などを全国共通の絶対能力と見なさない。
- まだ基礎能力スコアの計算や本番UIに連結しない。
- 外部サイトのスクレイピング・有料データ取得・API呼出はこの変更に含めない。
- 予想後に保存された情報、人気・確定着順・確定オッズは能力評価入力に使わない。
