# 展開図の原座標再現と4角前方検証（2026-11-14）

## 実装上の発見

従来の展開図は、`netkeiba_start_rank` / `netkeiba_corner3_rank` / `netkeiba_corner4_rank` の順位を一度取得した後、固定割合 `34% / 23% / 17% / 12% / 9% / 5%` の**独自の6段**に再配置していた。そのため、元のnetkeiba AI展開予測の各段に含まれる馬番が異なった。

一方、保存されたnetkeiba新聞HTMLを解析した結果からは、各馬の
`_estimated_position_start` / `_estimated_position_corner3` / `_estimated_position_corner4`
に**元の図の top / left 百分率**が残っている。例：
`top=-4%, left=53.91%, SpeedUp_01`

この **topは表示上の横レーン、leftは図の先頭側からの前後位置** に使われ、単なる順位のみから元の図の段差を復元することはできない。

### 新しい表示

- JRA/NAR、スタート後/3角/4角の各段階で、保存済みtop/leftがその段階の対象全頭に揃えば原座標を使用。元の段差・左右間隔を維持
- netkeibaの元座標は前方ほどleftが小さい。従来の回り方向表示を維持するため、右回りはそのまま、左回りはxのみ左右反転
- 1頭でも欠ける段階は、以前の順位ベースの簡易配置に段階ごとフォールバック（2つの座標系を同じパネルで混ぜない）
- 各段階に「元座標による配置」または「簡易配置」を表示。netkeibaの画像・馬イラスト自体を再配布せず、独自のSVG馬アイコンを使用
- 既存の純能力・ランク・正式印・発走前予測・オッズには影響なし
- 「保存予測」はレースの実際の通過位置・馬身差・馬場内外の正確な進路ではない

### 元座標の実データ確認

`20261111_all_結果払戻付き.keiba` 内、NAR 48レース・538頭を確認し、**536頭**の4角top/left原座標を確認（欠損2頭）。元データで使われるtopの代表値は `-4, 12, 30, 46, 64, 80`、leftは概ね `0〜105.5`。

例：11/11名古屋1Rは同一top=-4の5頭の4角予測順位が2位・3位・5位・9位・11位に分かれている。したがって、netkeiba展開図の**一番上の横一列は「前方5頭」ではない**。前後関係はleft（順位）で確認する。

## 検証範囲・注意

- ここでの「前方」は**netkeiba保存の発走前4角位置予測**であり、実際に4角を前方通過した馬とは別
- 11/7・8と11/11のデータは異なるフォーマットで別日に集計した。サンプルの同一馬、前売りレースや欠損は厳密な出走頭数基準で再確認が必要
- 仮説を発見した後にその期間で見直した探索的な結果で、未使用日の前向き検証ではない
- 馬券回収率は検証していない。候補頭数、券種、最終オッズで結果が変わる
- 11/14福島3Rのユーザー添付画像は展開図の前後・レーン差異の根拠。**同レースの元.keibaファイルそのものはこの検証時点で手元にない**ため、当日画面で同一馬番レーンになることは未確認
- 元データに座標がないレースは網羅できない。保存元のnetkeiba画面が後から更新された場合、取得時点の予測とは差が出る場合がある
