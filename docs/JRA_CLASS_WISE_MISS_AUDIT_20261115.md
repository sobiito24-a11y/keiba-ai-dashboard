## クラス入力の不整合（本番コード修正済み）
11/7・8・14の保存JRAには、`芝…右 A`、`芝…左 B` の**コース区分を地方級のA級/B級として扱った11R**があった。具体例: 土湯温泉特別1勝→A級、木津川特別2勝→B級、ノベンバーS3勝→B級、みちのくS OP→A級。旧値から作った昇降級や対戦クラス補正を、そのまま予測精度改善の根拠として使ってはいけない。クラスヘッダー優先修正・回帰テストをmainで管理し、新たな予測で検証する。

## 追加で実装・検証する場合の安全条件
1. JRAクラス `新馬/未勝利/1勝/2勝/3勝/OP/L/G3/G2/G1` と、年齢制限・芝ダート・平地/障害を独立して保存。過去走も同条件で確認。判定不能は「不明」であり0点や降級とは扱わない。
2. レースの「前走クラス」「今回クラス」の比較は明示的な競走条件のみに限定。前走の着順、対戦馬の次走成績、昇級経験、斤量変化、休養＋調教、同コース・距離実績を**別々のエビデンス**として扱い重複加点しない。
3. 新規モデルは必ず `research_only`、正式のS/A/B/C/D・Top5・印・オッズ・馬券推奨を変更しない。レースごとの取りこぼしと新たに入れた馬の不的中も両方記録する。
4. 未使用レースの期間別・クラス別の Top1、Top5、3着以内捕捉、Brier/校正、候補点数、欠損率を比較して初めて本採用を判断する。クラス単位の小サンプルで推定を確定させない。
5. 重賞研究は開催場・芝ダ/距離・馬場状態（良/稍重/重/不良）・実4角・ペース・年齢を同一条件で照合。確認できないデータは「未検証」と表示し過去の結果で今回の馬に自動加点しない。
