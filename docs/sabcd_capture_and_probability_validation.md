# 発走前ランク保存・評価誤差・確率補正・時系列検証

4項目の実装・検証結果。保存機能はコードに追加。確率補正は研究用の試作とし、自動ランク変更は有効にしない。既存の.keibaは変更していない。

## 1. 発走前に確定したランクの保存

画面で確定した統合SABCD・元研究評価・補正理由・計算材料・クラス判定・計算コードのハッシュ・実際の確定時刻を保存する。画面を開かずに書き出す場合は表示用の計算経路で確定し、保存後の画面はその値を使う。表示時の確定と書き出し時の確定はoriginで区別する。保存済み値は現行モデルが変わっても維持する。

保存先は.keibaのレース直下、mobile_snapshot、PredictionResultのdebug_info内のintegrated_sabcd_snapshot。現在のモデル値・相対強度を「実証済み馬券内確率」と呼ばない。

発走前かどうかは予測作成時刻だけでなく実際の確定時刻でも確認する。発走後に初めて書き出した値はpost_start、発走時刻不明などはtime_unverifiedとする。旧ファイルに保存ランクがなければ、現在の再計算を当時の値として追記せず、画面でも参考再計算と表示する。既存ファイルへ遡及して正しい当時ランクを作る機能ではない。

## 2. 評価のズレを調べる方法

純能力と予測4角だけでなく、コース・距離・平均指数の相対順位、近走着順・指数推移・変動、同条件経験、騎手実績、年齢・性別・斤量、間隔、乗替、クラス、距離変更、ペース、出走頭数、相手との指数差、材料不足と矛盾を使った。距離適性×騎手、昇級×近走、ペース×位置取りなどの組合せも含む。欠損は学習期間内の中央値と欠損フラグで区別する。馬名・レース結果・実測4角・確定オッズは入力しない。

対象377R・4,097頭のうち未判定15頭を確率モデルから除外。学習に必要な前半を除いた、後続期間221R・2,382頭の予測誤差を集計した。以下は検証期間に見られた記述的なズレであり、この結果を見て新しい昇降格条件を追加してはいない。

|条件|ランク|頭数|実際の馬券内率|ランクだけの推定|補正後の推定|
|---|---|---:|---:|---:|---:|
|能力と位置取りの順位差大|C|145|34.48%|26.63%|27.81%|
|能力と位置取りの順位差大|D|238|14.71%|10.69%|9.93%|
|距離変更200m以上|C|119|36.13%|26.43%|27.36%|
|距離変更200m以上|A|45|57.78%|61.98%|65.69%|
|近走材料3走未満|B|33|36.36%|45.65%|51.61%|
|適性と能力の順位差大|D|288|6.60%|10.78%|8.48%|

例えばCの距離変更馬には過小評価が見られる一方、Aの距離変更馬や近走材料の少ないBでは補正後も過大評価が残った。同じ材料をランクに関係なく一律加点・減点する方法では足りない。またDの能力と位置取りが食い違う群は、今回の補正でむしろ過小評価が拡大した。改善箇所と悪化箇所が併存するため、そのまま本番採用しない。

「順位差大」は頭数で正規化した順位の差が0.4以上。「同条件」は保存された近走内の同場・同距離・同馬場種別であり、生涯実績ではない。特徴量同士が重なるので、この表から因果関係や各要素単独の効果は断定できない。

## 3. 小さな確率補正の試作

学習期間だけから求めたランク別馬券内率を基準に、正則化したロジスティック補正を加えた。基準率は20頭分の全体平均で平滑化。正則化強度50、各特徴量の標準化も学習期間だけで計算し、極端値は±5標準偏差で制限。補正幅は±8ポイントまで。結果を見てこの設定を変更していない。

この基準率は現行モデルが画面表示する確率ではなく、今回の比較用に学習した確率である。「現行システム全体の精度がこの率だけ向上した」という意味ではない。比較用の生の研究スコアを校正済み確率と見なしていない。

## 4. 期間を分けた検証

同一レースの馬が学習と検証に分かれないよう日付で分割。各区間では未来の結果で学習しない。後の区間で過去の検証日を学習に追加する拡大型の検証。11/18は条件探索に使ったため今回の合否集計には含めていない。

|学習期間|検証期間|検証頭数|補正前の誤差|補正後の誤差|
|---|---|---:|---:|---:|
|11/9〜11-11|11-12〜11-13|973|0.159265|0.156544|
|11/9〜11-13|11-14〜11-15|672|0.160056|0.158130|
|11/9〜11-15|11-16〜11-17|737|0.154007|0.152454|

確率誤差（Brier score、小さいほど良い）は合計0.157861→0.155726。相対で1.35%減少した。これは的中率が同じポイントだけ上がったという意味ではない。Log lossも0.485062→0.478372に低下。

レース単位で2,000回再抽出した誤差差の参考95%区間は-0.003574〜-0.000606。同じ馬の別レースや開催日間の依存までは取り除けておらず、将来の改善保証ではない。

### 単純な確率校正だけとの追加比較

## 確率をランクに反映する試算は不採用

学習期間の隣接ランクの基準率の中点を仮の境界とし、境界から5ポイント以内・隣接ランクへの1段階だけ移動を試算した。これは現行ランクを置き換える確定済み境界ではない。

|ランク|変更前の馬券内|試算後の馬券内|
|---|---:|---:|
|S|63/70頭（90.00%）|112/153頭（73.20%）|
|A|155/244頭（63.52%）|106/161頭（65.84%）|
|B|174/399頭（43.61%）|174/399頭（43.61%）|
|C|153/525頭（29.14%）|153/525頭（29.14%）|
|D|114/1144頭（9.97%）|114/1144頭（9.97%）|

A→Sが85頭（馬券内50頭、58.82%）、S→Aが2頭（馬券内1頭）。S全体の馬券内率が90.00%から73.20%へ低下し、昇格したA群自体も元のA全体より良くない。B/C/Dは今回の小幅補正と仮境界では動かなかった。確率誤差の改善と、上位ランクの質の改善は別であるため、ランク変更は有効にしない。

## 採否と限界

- 保存機能：実装。新規保存について表示値・確定時刻・由来を追跡できる。
- 評価のズレ：分析済み。材料不足・距離変更・能力と適性／位置取りの食い違いなどで、ランクごとに異なるズレが残る。
- 確率補正：試作・検証済み。全体の確率誤差には小さな改善があるが、会場差が残るため研究専用。
- 自動昇降格：不採用。本番のランク・印・買い目への接続なし。

元の統合ランクはクラスを「判定不可」とした歴史データの再構成であり、保存された当時の表示値ではない。既存補正の開発や前回の分析でこの期間の結果を既に見ているため、完全に未使用の検証データではない。厳密な本番採否は、新しく保存する発走前ランクを使った将来日の検証が必要。未来の結果がない段階でその検証まで完了したとはしない。

調教・厩舎コメント・馬体重などの大部分未取得項目は検証できていない。確率補正は個別の3着内率であり、全頭の合計を3にする制約やオッズ・収益性の検証は実施していない。

## 保存成果物

確率補正_検証条件.json：固定した期間・係数・補正幅。
確率補正_期間別検証.json：期間・会場・ランク・条件別の数値とモデル。
確率補正_検証馬明細.json：全検証馬の予測値・実着順・仮ランク。
確率補正_研究用モデル.json：11/17までで学習した研究専用パラメータ。本番利用無効。
確率補正_単純校正との追加比較.json：追加比較の結果。

## 再実行

`python research/sabcd_probability_validation.py --rows <別日検証_全頭明細.json> --races <validation_inputs.json> --output <出力フォルダ>`

入力は馬番・馬名・全出走馬を結果と照合した既存分析JSON。将来日へ流用する場合は分割日付とランクの由来を明示的に新しい実験として定義する。このスクリプトは11/19の固定実験を再現するためのものであり、本番予測ではない。

保存試験は `python -m pytest tests/test_sabcd_snapshot.py tests/test_sabcd_probability_research.py tests/test_prediction_snapshot.py`。旧ファイルの再計算値を当時の値として保存しないこと、発走後／時刻不明を区別すること、書き出しと復元で保存値が一致することを確認する。
